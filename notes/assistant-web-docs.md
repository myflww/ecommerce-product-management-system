# AI 管家联网搜索依据（1.6）

核对日期：2026-11-13。依据为 [DeepSeek Search API](https://api-docs.deepseek.com/api/search/) 与 [Search & Fetch 官方指南](https://api-docs.deepseek.com/guides/search/)。

独立搜索端点为 `POST https://api.deepseek.com/v1/tools/search`，沿用官方 DeepSeek 服务的 Bearer 密钥。请求只有用户明确填写的公开关键词（1 至 128 字符）、结果数量和是否需要正文，不含聊天历史、公司知识片段、图片、SKU、定位或账号资料。Search 请求没有模型字段，本实现因此将检索与聊天模型分开；配置的聊天模型可以继续回答，不能据此认为其他兼容服务也自带此搜索接口。

仅在用户本次选择联网且上层授权通过后调用；模块本身没有定时器，不在启动或能力检查时联网。只向固定官方端点发送密钥，拒绝自定义域名和重定向。结果只使用搜索 API 已返回的公开网页材料，不逐个请求网页链接，不代登录，也不绕过网站限制。

一次最多 6 条结果，全部来源 JSON 最多 14000 字符；正文过长截取，整个响应体最多 2 MiB、请求总时限 25 秒。来源链接、摘录和日期传给界面供核查。标题和正文均是不可信资料，不执行里面的指令；URL 过滤私有地址、用户信息与危险协议，也不引入网站图标或脚本。

搜索按服务商当期规则另行计费，区别于模型 Token 费用和本地软件的请求次数限制。是否可用仍受账户权限、余额、限流与网络影响；本地支持不等于已验证某个账户的真实搜索权限。失败、超时或空结果会明确标记，不能宣称已查到网络证据，普通问答由上层继续处理。测试只使用模拟服务响应，没有调用真实付费搜索。
