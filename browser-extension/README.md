# 觅同 · 当前页面采集

这是 Edge / Chrome 的本地扩展。你先在平时使用的浏览器里正常打开 Temu 商品或店铺，再点击扩展读取页面。它不会新开登录窗口，不代填密码，不读取 Cookie，也不自动翻页或绕过平台验证。

安装：在 Edge 打开 `edge://extensions`（Chrome 为 `chrome://extensions`），开启“开发人员模式”，点击“加载解压缩的扩展”，选择本文件所在文件夹。把扩展固定到工具栏更方便使用。此版本为本地加载版，未上架浏览器扩展商店。

使用：

1. 正常打开商品详情页或店铺页，确认商品、地区和价格显示正常。
2. 点击扩展 →“读取当前页面”，核对所属店铺链接和店铺名称，勾选店铺归属确认，加入本批。
3. 可以手动打开其他商品继续采集。一批最多 20 款商品、20 个页面。同一商品重复采集会替换本批旧记录，详情页会替换同商品的店铺卡片。
4. 点击“导出采集文件”，回到觅同的“批量入库 → 从浏览器页面导入”，选择下载的 JSON 文件。
5. 在觅同预览中核对商品、图片、规格与报价；同款可并入已有商品，确认后才会入库。

店铺页会显示当前实际加载的商品数量，可以选择“第 1–20 款 / 第 21–40 款……”并逐项勾选，本批最多导出 20 款。导出并清空后，重新读取页面、选择下一组即可继续；尚未加载的商品需你先在网页上正常滚动加载。这不能保证是全店；想保留更多规格请打开商品详情逐个采集。未读到的规格、币种和价格不会猜测，也不会把一个选中规格的售价复制给所有规格。平台隐藏的数据仍可能缺失，部分报价可能取不到；这套扩展不承诺已完成真实 Temu 全店采集验收。

扩展只请求 `activeTab`、`scripting`、`storage` 三项权限。只有你点击读取时才运行页面采集脚本，只保留公开商品字段（名称、图片地址、商品/店铺/规格编号和独立报价）。原始网页、完整注水数据、账号输入框、密码、浏览历史与 Cookie 不会保存。公开商品资料暂存在当前浏览器扩展的本地存储中，导出文件也保存在本机；插件不向外部服务器发送数据。导入觅同时主图会由软件安全下载，若图片无法下载会提示，不能当作成功入库。

清空本批只移除扩展里的待导出商品，不删除下载文件或觅同商品。卸载扩展会清掉扩展本地数据；先导出需要保留的内容。
